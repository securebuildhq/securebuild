# Notifications

SecureBuild's notification system keeps you informed about security updates, new releases, vulnerability discoveries, and system events that matter to your operations. Understanding how to configure and use notifications helps you maintain security posture and operational awareness.

## Why Use Notifications?

SecureBuild notifications keep you informed about security updates, new releases, and vulnerability discoveries. Get immediate alerts when vulnerabilities are discovered, know when security patches are available, and maintain compliance with automated audit trails. Notifications reduce manual monitoring overhead while ensuring you never miss critical security updates.

## Quick Start: Dashboard Configuration

Notifications can be configured directly in the SecureBuild dashboard at [https://securebuild.com/dashboard/notifications](https://securebuild.com/dashboard/notifications). The dashboard provides an intuitive interface for:

- **Adding Notifications**: Click "Add Notification" to create new notification rules
- **Selecting Images**: Choose specific images or subscribe to all images
- **Choosing Notification Types**: Select from Email or Webhook delivery methods
- **Configuring Event Types**: Enable notifications for:
  - Tag updated (repushed due to vulnerability fixes)
  - New tag available
  - CVE found in SecureBuild image
- **Managing Existing Notifications**: View, edit, or delete current notification rules

The dashboard interface includes built-in documentation and examples to help you understand each notification type and configure webhook integrations properly.

### 2. Custom Webhooks

```python
# webhook-integration.py
class CustomWebhookHandler:
    def __init__(self, webhook_url, secret_key):
        self.webhook_url = webhook_url
        self.secret_key = secret_key

    def send_notification(self, notification):
        """Send notification to custom webhook endpoint"""

        payload = {
            'timestamp': notification.timestamp,
            'type': notification.type,
            'severity': notification.severity,
            'data': notification.data
        }

        # Sign payload for security
        signature = self.sign_payload(payload)

        headers = {
            'Content-Type': 'application/json',
            'X-SecureBuild-Signature': signature,
            'X-SecureBuild-Event': notification.type
        }

        response = requests.post(
            self.webhook_url,
            json=payload,
            headers=headers,
            timeout=30
        )

        if response.status_code != 200:
            raise WebhookDeliveryError(
                f"Webhook delivery failed: {response.status_code}"
            )

    def sign_payload(self, payload):
        """Create HMAC signature for payload verification"""
        import hmac
        import hashlib

        payload_bytes = json.dumps(payload, sort_keys=True).encode()
        signature = hmac.new(
            self.secret_key.encode(),
            payload_bytes,
            hashlib.sha256
        ).hexdigest()

        return f"sha256={signature}"
```

## Advanced Notification Features

### 1. Intelligent Filtering

```python
# intelligent-filtering.py
class NotificationFilter:
    def __init__(self):
        self.user_preferences = self.load_preferences()
        self.noise_reduction = NoiseReductionEngine()

    def should_send_notification(self, notification, recipient):
        """Determine if notification should be sent to recipient"""

        # Check user preferences
        if not self.matches_preferences(notification, recipient):
            return False

        # Check for duplicate notifications
        if self.is_duplicate_notification(notification, recipient):
            return False

        # Apply intelligent noise reduction
        if self.noise_reduction.is_noisy(notification, recipient):
            return False

        # Check business hours preferences
        if not self.is_appropriate_time(notification, recipient):
            return False

        return True

    def matches_preferences(self, notification, recipient):
        """Check if notification matches recipient preferences"""

        prefs = self.user_preferences.get(recipient, {})

        # Check severity threshold
        min_severity = prefs.get('min_severity', 'medium')
        if not self.meets_severity_threshold(notification.severity, min_severity):
            return False

        # Check image interest
        interested_images = prefs.get('images', [])
        if interested_images and notification.image not in interested_images:
            return False

        return True

    def is_duplicate_notification(self, notification, recipient):
        """Check for recent duplicate notifications"""

        recent_notifications = self.get_recent_notifications(
            recipient,
            hours=24
        )

        for recent in recent_notifications:
            if self.notifications_similar(notification, recent):
                return True

        return False
```

## Integration Examples

### 1. ITSM Integration (ServiceNow)

```python
# servicenow-integration.py
class ServiceNowIntegration:
    def __init__(self, instance_url, username, password):
        self.instance_url = instance_url
        self.auth = (username, password)

    def create_incident(self, notification):
        """Create ServiceNow incident for critical notifications"""

        if notification.severity != 'critical':
            return  # Only create incidents for critical issues

        incident_data = {
            'short_description': f"SecureBuild: {notification.title}",
            'description': notification.description,
            'urgency': self.map_severity_to_urgency(notification.severity),
            'category': 'Security',
            'subcategory': 'Container Security',
            'caller_id': 'securebuild_system',
            'assignment_group': 'security_team'
        }

        response = requests.post(
            f"{self.instance_url}/api/now/table/incident",
            auth=self.auth,
            json=incident_data,
            headers={'Content-Type': 'application/json'}
        )

        if response.status_code == 201:
            incident = response.json()
            return incident['result']['number']
        else:
            raise ServiceNowError(f"Failed to create incident: {response.text}")
```

### 2. Notification History

```python
# notification-history.py
class NotificationHistory:
    def __init__(self):
        self.storage = NotificationStorage()

    def get_history(self, user_id, filters=None, limit=50):
        """Retrieve notification history for a user"""

        query = {
            'recipient': user_id,
            'limit': limit
        }

        if filters:
            if 'start_date' in filters:
                query['timestamp__gte'] = filters['start_date']
            if 'end_date' in filters:
                query['timestamp__lte'] = filters['end_date']
            if 'types' in filters:
                query['type__in'] = filters['types']

        return self.storage.query_notifications(query)

    def mark_as_read(self, notification_id, user_id):
        """Mark notification as read"""

        return self.storage.update_notification(
            notification_id,
            {'read_by': user_id, 'read_at': datetime.utcnow()}
        )

    def get_unread_count(self, user_id):
        """Get count of unread notifications"""

        return self.storage.count_notifications({
            'recipient': user_id,
            'read_by__exists': False
        })
```

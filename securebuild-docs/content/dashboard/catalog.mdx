# Catalog

The **Catalog** section provides access to the complete SecureBuild catalog of secure images and packages. This is your central hub for browsing, discovering, and subscribing to SecureBuild images.

## Catalog Overview

- **Total Images**: The catalog shows "Showing 33 images" indicating the breadth of available options
- **Organization Images**: Displays "Your Organization Images" - images your organization is currently subscribed to
- **Subscription Status**: All images show "Subscribed" status in green badges

## Image Cards

Each image is presented as a detailed card showing:

### Visual Elements

- **Icon**: Distinctive icon representing each image (e.g., elephant for postgres, Kubernetes wheel for kubectl)
- **Subscription Badge**: Green "Subscribed" pill indicating current subscription status
- **Category Tags**: Color-coded tags like "Utilities", "Development", "Infrastructure", "Kubernetes"

### Image Information

- **Name**: Clear image name (e.g., "bash", "postgres", "kubectl")
- **Description**: One-line description of the image's purpose and functionality
- **Price**: Monthly subscription cost 

### Security Metrics

- **Fixed CVEs**: Number of vulnerabilities that have been fixed (e.g., "6" for bash, "151" for kubectl, "95" for postgres)
- **Security Status**: Higher numbers indicate more vulnerabilities were patched during SecureBuild's rebuild process

## Actions

- **View Details**: Click "View Details" on any image card to see comprehensive information
- **Subscription Management**: All shown images are already subscribed to
- **Browse All**: Access the full catalog of 33+ available images

This section provides a comprehensive view of your subscribed images and their security benefits.

# Notification History

The **Notification History** section provides comprehensive tracking of all notification delivery status and history.

## Summary Statistics

The interface displays key metrics in four cards:

- **Total Events**: Total number of notifications sent (e.g., 45)
- **Success Rate**: Percentage of successfully delivered notifications (e.g., 100%)
- **Failed**: Number of failed deliveries (e.g., 0)
- **Pending/Processing**: Notifications currently being processed (e.g., 0)

## Recent Events

The **Recent Events** section shows a detailed list of all notification activities:

### Filtering Options

- **Time Range**: "All Time" dropdown for date filtering
- **Image Filter**: "All Images" dropdown to filter by specific images
- **Status Filter**: "All Status" dropdown to filter by delivery status

### Event Details

Each notification entry shows:
- **Status Icon**: Green checkmark for successful deliveries
- **Notification Type**: Envelope icon indicating email notification
- **Image & Tag**: Specific image and tag (e.g., "postgres:17")
- **Message**: Description of the event (e.g., "Tag updated (repushed due to vuln fixed)")
- **Recipient**: Email address that received the notification
- **Delivery Status**: "delivered" badge with timestamp

### Example Events

The interface shows multiple postgres:17 notifications:
- **Message**: "Tag updated (repushed due to vuln fixed)"
- **Recipient**: devops@company.com
- **Status**: All marked as "delivered"
- **Timestamps**: Chronological list from recent dates

## Understanding Delivery Status

### Successful Deliveries

- **Green Checkmark**: Indicates successful delivery
- **"delivered" Badge**: Confirms the notification was sent
- **Timestamp**: Shows when the notification was delivered
- **Recipient Confirmation**: Email was successfully sent to the recipient

### Failed Deliveries

- **Red X Icon**: Indicates delivery failure
- **Error Details**: Information about why the delivery failed
- **Retry Options**: Options to resend failed notifications
- **Troubleshooting**: Steps to resolve delivery issues

### Pending/Processing

- **Orange Warning Icon**: Indicates notification is being processed
- **Queue Status**: Shows position in delivery queue
- **Estimated Delivery**: Approximate time for delivery
- **Processing Time**: How long the notification has been processing

## Use Cases

- **Delivery Tracking**: Monitor notification delivery success rates
- **Audit Trail**: Maintain records of all security notifications sent
- **Troubleshooting**: Identify and resolve delivery issues
- **Compliance**: Provide notification history for audit purposes
- **Team Visibility**: Track which team members received which notifications

## Filtering and Search

### Time Range Filter

- **All Time**: View all notifications ever sent
- **Last 7 Days**: Recent notifications only
- **Last 30 Days**: Past month of notifications
- **Custom Range**: Select specific date range

### Image Filter

- **All Images**: Show notifications for all images
- **Specific Image**: Filter by individual images (e.g., postgres, kubectl)
- **Multiple Images**: Select multiple images to compare

### Status Filter

- **All Status**: Show all notification statuses
- **Delivered**: Only successfully delivered notifications
- **Failed**: Only failed deliveries
- **Pending**: Only notifications being processed

## Best Practices

- **Regular Monitoring**: Check notification history regularly
- **Success Rate Tracking**: Monitor delivery success rates
- **Failed Delivery Investigation**: Investigate and resolve failed deliveries
- **Audit Compliance**: Use history for compliance and audit purposes
- **Team Communication**: Share notification status with team members

## Getting Started

1. **Review Summary Statistics**: Check overall delivery performance
2. **Filter Recent Events**: Use filters to find specific notifications
3. **Investigate Failures**: Look into any failed deliveries
4. **Monitor Success Rates**: Track delivery success over time
5. **Export History**: Download notification history for reporting

This section helps you maintain visibility into your notification delivery performance and troubleshoot any issues.

# Service Accounts

The **Service Accounts** section provides credentials and tokens for programmatic access to your subscribed images. This is essential for CI/CD pipelines, Kubernetes deployments, and automated systems.

## Registry Credentials

The **Registry Credentials** section provides your authentication details for the container registry:

- **Registry Username**: Auto-generated username based on your team
- **Copy Function**: Click the copy button to easily copy your username
- **Team-Based**: Username is automatically generated based on your team membership
- **Authentication**: Use this username with access tokens for registry authentication

## Access Tokens

The **Access Tokens** section allows you to manage service account tokens for programmatic access:

### Creating Tokens

- **Create Token Button**: Click "+ Create Token" to generate new access tokens
- **Token Management**: Create tokens for different environments, services, or team members
- **Naming Convention**: Give tokens descriptive names like "CI/CD Pipeline", "Production", "Development"

### Token Table

The interface displays all your access tokens with detailed information:

**Token Information:**
- **Name**: Descriptive name for the token
- **Token**: Masked token value showing first few characters followed by "..."
- **Last Active**: When the token was last used (e.g., "8/18/2025", "Never")
- **Expires On**: Token expiration date ("Never" for non-expiring tokens, specific dates for expiring ones)
- **Created At**: When the token was originally created

**Token Actions:**
- **Edit**: Modify token settings and permissions
- **Refresh**: Regenerate the token (invalidates the old one)
- **Delete**: Remove the token permanently

## Security Best Practices

- **Token Rotation**: Regularly refresh tokens to maintain security
- **Environment Separation**: Use different tokens for different environments
- **Least Privilege**: Create tokens with only necessary permissions
- **Monitoring**: Track token usage and deactivate unused tokens
- **Expiration**: Set appropriate expiration dates for tokens

## Getting Started

1. **Copy Registry Username**: Use the copy button to get your registry username
2. **Create Access Token**: Click "+ Create Token" to generate your first token
3. **Configure Authentication**: Use the username and token for registry authentication
4. **Test Access**: Verify that your tokens work with your CI/CD or deployment systems

This section is essential for integrating SecureBuild images into your automated workflows and production systems.

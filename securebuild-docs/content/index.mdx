# Welcome to SecureBuild Documentation

**SecureBuild provides enterprises with zero-CVE container images built from source, while sharing revenue with the open source maintainers who create the software.**

We partner directly with open source project maintainers to deliver secure, enterprise-ready container images that eliminate vulnerabilities and provide complete supply chain transparency.

## What SecureBuild Does

### 🤝 Partner with Open Source Maintainers
We work directly with the creators and maintainers of critical open source projects, ensuring they're involved, consulted, and compensated for their work. **We share 70% of direct subscription revenue** with the maintainers whose projects we secure.

### 🔨 Rebuild Everything from Source
Every image is rebuilt from source using our trusted build infrastructure. We don't just patch existing images—we compile and build everything fresh, mapping all dependencies and creating complete Software Bills of Materials (SBOMs).

### 🛡️ Eliminate Vulnerabilities
Our automated pipeline identifies and removes all addressed CVEs, delivering true **zero-CVE container images**. We monitor continuously and maintain a **6-day SLA on patching critical vulnerabilities**.

### 🏢 Enterprise-Ready Security
Built for enterprise environments with:
- **SOC2, HIPAA, and PCI-DSS compliance** capabilities
- **Complete SBOM generation** for supply chain transparency
- **Cryptographic signing** and attestation
- **Isolated build environments** for maximum security
- **Multi-architecture support** (x86_64 and aarch64)

## How It Works

### 1. Source Based Rebuilds
We rebuild open source projects from their source code using secure, isolated build environments. This ensures complete visibility into what goes into your container images.

### 2. Dependency Security
Our build process maps your entire dependency graph, identifying and patching vulnerabilities across all layers—from base OS packages to application dependencies.

### 3. Continuous Monitoring
We continuously monitor for new vulnerabilities and automatically rebuild affected images, ensuring your infrastructure stays secure without manual intervention.

### 4. Enterprise Distribution
Secure images are distributed through private registries with enterprise-grade access controls, audit logging, and compliance documentation.

## Technical Architecture

### Build Pipeline
- **Isolated VMs** for each build to prevent cross-contamination
- **Multi-architecture builds** supporting x86_64 and aarch64
- **Comprehensive scanning** with tools like Grype for vulnerability detection
- **SBOM generation** using industry-standard formats
- **Cryptographic signing** with Cosign for image attestation

### Security Features
- **Zero Trust Architecture** - Every build runs in an isolated environment
- **Vulnerability Scanning** - Continuous monitoring and automated patching
- **Supply Chain Attestation** - Cryptographically signed build provenance
- **Access Controls** - Enterprise-grade authentication and authorization
- **Audit Logging** - Complete traceability of all build and access events

## Why SecureBuild?

Supply chain attacks have made every security team re-evaluate how they trust software. Traditional approaches of pulling images from public registries and hoping they're secure aren't sufficient for enterprise environments.

SecureBuild provides a fundamentally different approach: **we rebuild everything from source** using trusted infrastructure, **eliminate all known vulnerabilities**, and **share the economic value** with the open source maintainers who create the software we all depend on.
